# Changes 2026-11-06: Thursday exit fixes and Kotak Neo integration

## Thursday exit (`scripts/Thursday-Fno-Exit-Orders-V1.py`)

- **Reset guard:** `ORDERS_LIVE_THU` is no longer reset while an open Thursday long has no authorization key (`_unmanaged_thu_long_positions`). Fails closed on Redis errors.
- **Trail seeding:** the trail max is floored by the Alpha FSM `peak_ltp` for the matching leg (`_fsm_peak_for_symbol`), so the trail no longer restarts from entry price when a leg was unauthorized. Only the ongoing cycle snapshot is used.
- **Reconciliation alert:** `[THU-RECON]` CRITICAL when the FSM marks a leg closed but the broker still holds it (`_fsm_closed_legs_with_open_positions`). Log only; no order is placed.

## Config (`config.py`)

- Added the missing `from typing import Optional`. Without it, importing `config` raised `NameError`.

## Kotak Neo (`common/kotak_neo_adapter.py`, `common/entry_order_manager.py`)

- **Instrument keys:** resolved from `masterscrip/file-paths` -> F&O CSV, cached per day. Fails closed if the key is missing.
- **Order payload:** place, SL-M and market exit use the documented `jData` form field. Orders with no instrument key are blocked before any request.
- **Net quantity:** includes carry-forward (`cf*`) buy and sell quantities.
- **Network errors on order calls:** reported as `unknown_state`; entry maps this to status `unknown`, not `rejected`.
